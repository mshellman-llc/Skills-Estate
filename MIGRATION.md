# Restored Skills Estate

The initial release shortened detailed workflows into brief entrypoints. This revision restores the scripts, examples, failure handling, templates and references needed to perform the work. Canonical entrypoints live in `skills/`; routing instructions live in `agents/`. The estate includes 78 skills, including the newer sales-process-mapping and sales-journey-critique skills already published on GitHub.

The maintained writing-integrity skill and its current pattern references are preserved. Every skill reads `policies/writing.md`; built packages carry the policy and writing runtime. `policies/brand.md` is the shared brand authority. A confirmed project profile supplies a client's identity; the neutral profile supplies the default.

The former company namespace has been replaced throughout reusable source and tool paths. The substitution preserves source lines and workflow content. Private recovery snapshots retain the originals and earlier generated outputs. Existing project-level hook installations are separate from the assistant skill folders; this migration does not rewrite a client's repository configuration.

`tools/estate.py build` assembles the full runtime dependencies for each skill. `bundle` produces individual ZIP packages. `adopt` preserves conflicting local entries in a dated backup and links the built packages into Claude Code and Codex. The repository pointer lets both assistants locate the same canonical checkout. `status` compares actual installed bytes with the current build.

The tests exercise source preservation, isolated packages, document generation, quote reconciliation, local records, Salesforce preparation and refusal paths, reversible installation and drift detection. A successful package or local test does not establish a live integration. Salesforce validation and deployment require an explicitly confirmed test org; none was supplied. Claude account uploads and account-synced plugin copies require their own destination checks and are not inferred from local installation.

The source archive has no blanket redistribution license. Keep private project data, credentials and confirmed contract profiles outside reusable packages. Preserve third-party notices.

How these choices work

Visibility controls the content included in a website export, its search results and direct skill links. A workflow example is omitted if it requires a skill hidden from that target. The preview report identifies those requirements.

Featured items appear first within their group. Lower order numbers appear earlier. Featured and order choices do not make a hidden item visible.

Download availability is a separate choice. Complete plugin ZIPs retain their workflows and required helpers. Hiding a website entry does not edit an existing plugin or withdraw packages already published on GitHub.

The public export includes the selected catalog, a standalone page and a framework-independent web component. It does not include this manager, your full inventory or the show/hide configuration. Commit the choices file alongside the source when you want GitHub to preserve that selection.

How to install skills

The skills install as plugins from the Skills Estate marketplace, which is the private mshellman-llc/Skills-Estate repository. You need access to that repository. Each skill's overview names the plugin that contains it.

  1. Claude app (claude.ai or desktop): open Customize, then Plugins, then Add, and add the marketplace mshellman-llc/Skills-Estate with automatic sync on. Then add the plugin you need.
  2. Claude Code: run /plugin marketplace add mshellman-llc/Skills-Estate, then /plugin install PLUGIN@MARKETPLACE, and turn on auto-update for the marketplace in /plugin.
  3. Codex on a Mac: run python3 tools/estate.py update from a Skills Estate checkout.

After installing, ask for the work in plain words, such as the example request on each skill. In Claude Code you can also name the skill, for example /estate-delivery:acceptance-testing. The estate-personal plugin is opt-in and holds the career and personal workflows.

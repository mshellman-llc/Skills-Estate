# Publishing

Distinguish the writable source, generated package, hosted destination, and
installed copy. Building a bundle does not publish it. Pushing Git does not prove
a website, marketplace, Claude skill, Cowork skill, or plugin was updated.

After publication, verify the destination's success response and listing or
public/private URL as appropriate. For installations, read back the installed
version or bytes. Do not infer cloud removal from a local deletion.

Report each surface separately as unchanged, published, installed, or verified
live. Never combine several surfaces into a single `synced` claim without proof
from each one.

# Author writing profile

Use this method when the requested author has a confirmed profile supplied through the current task or an authorized private profile store. This workflow contains no person's voice, career evidence or personal scanner configuration.

## Select the author and context

Resolve the intended author, audience, purpose and format from the request. Locate only the profile explicitly supplied or authorized for this context. A person's name, shared account, installed connector or familiar path does not authorize reading their personal material. Do not search unrelated stores for a matching owner.

Read the profile's ownership, authorization, version and revocation state. Apply its voice only to that author and the permitted surfaces and contexts. Use [personal-writing-style-runtime](_runtime/personal-writing-style-runtime/WORKFLOW.md) for routing and precedence. If no applicable profile is available, use [writing-integrity](_runtime/writing-integrity/WORKFLOW.md) and plain drafting; do not invent an author's preferences.

## Apply the confirmed profile

Load the smallest confirmed rules and context overlay needed for the task. Preserve exact facts, legal meaning, scope, approval conditions and material uncertainty. A style preference cannot waive those requirements. Keep quotations unchanged. Preserve the author's intended directness or humor when supported by the supplied profile.

Separate internal evidence records from reader-facing copy according to the reader's purpose. Keep a qualification or correction notice when the reader needs it to understand a claim or act. A profile cannot require concealing a material limitation.

Review the complete result against its sources and the applicable profile. When an optional scanner is configured, inspect its path, supported profile options and storage authority before using it. Use only the explicitly confirmed profile; do not fall back to another person's scanner or learning store. A scan supports only its actual checks and does not replace reading.

## Maintain profile ownership

Apply corrections throughout the current artifact and session. Persist them only through the owner's authorized private learning workflow. Use [writing-style-builder](_runtime/writing-style-builder/WORKFLOW.md) for creating, correcting or revoking a profile; use Writing Integrity's explicit store for its learning workflow. Preserve before-and-after evidence privately when authorized. Do not embed profiles, raw examples, personal metrics or scanner configuration in this reusable module.

Report a missing profile or unperformed scan only when it affects the requested assessment. Never claim a profile was loaded, a correction saved or a scan run without its evidence.

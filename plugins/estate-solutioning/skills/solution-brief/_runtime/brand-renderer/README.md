# Brand Renderer

> Renders and release-gates the requested branded document, deck, workbook, PDF, webpage, email, Slack message, and piece of UI copy after proving the bundled brand and prose runtimes are present.

**What it does.** Renders and release-gates the requested branded artifact using a confirmed profile or the shared neutral policy.

**Use it when.** For Word or DOCX documents, PowerPoint or PPTX decks, Excel or XLSX workbooks, PDFs, HTML pages, one-pagers, reports, proposals, emails, Slack messages, and UI copy. Use when creating, reviewing, editing, exporting, or finalizing any branded output.

# Detailed feature specification

> Specify interfaces, persistence, recovery and applicable interaction behavior from the requested design scope.

**What it does.** Supplies the detailed UI and API specification mode in `write-feature-spec`. It preserves existing callers and record identity, separates proposals from inspected behavior, and defines observable acceptance. Use a file manifest when implementation planning is requested and rendered mockups when they resolve an interface decision.

**Use it when.** The requested specification needs this level of interface, data or interaction detail. Use the requested delivery format. Use a specification for a defect fix when the request or its scope calls for one. An API-only change does not require a UI mockup.

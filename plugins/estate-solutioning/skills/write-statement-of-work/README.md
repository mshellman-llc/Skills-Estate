# Statement of work

Draft or revise an editable statement of work from confirmed scope and the selected agreement using an available document tool. Preserve actual obligations, pricing, acceptance and approval state; missing terms remain visible in a labeled draft.

The optional Word generator supports a confirmed quote JSON and selected contract profile in its documented Waterfall, Agile, assessment and engagement-letter shapes. Use the document-tool route when that model cannot represent the actual agreement, including independently agreed fixed fees that differ from hourly billings.

Start with [SKILL.md](SKILL.md). The [synthetic quote](fixtures/quote.example.json) and [example contract profile](fixtures/contract.example.json) run without a proprietary pricing application. Actual provider identity, payment instructions, and contract approvals belong in the private project profile. Branding comes from the shared brand runtime.

The builder writes the DOCX, input and artifact hashes, and a resolution log. Run the selected-contract verifier, then render and inspect the pages before delivery. Packaging and content checks alone do not prove usable layout.

# Scope reference

Create a static option comparison or single-quote scope summary with the [full workflow](SKILL.md). The [build guide](build-guide.md) describes the standalone HTML and print route. The [validation contract](validation.md) defines the separate source and presentation records.

The bundled synthetic examples exercise different item hours, optional and deselected work, and multiple staffing plans. No live connector is required to use a dated export. A current live claim still requires a fresh read from the quote system.

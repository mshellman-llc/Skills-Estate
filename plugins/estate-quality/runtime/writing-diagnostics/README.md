# Writing diagnostics

Prose Pass is retired as a standalone skill. Use [Writing Integrity](_runtime/review-writing/WORKFLOW.md) for writing work. This source directory preserves its internal diagnostic tools, format registers and receipt compatibility.

Apply the [writing workflow](WORKFLOW.md) to all authored language. Internal records and agent instructions follow the same standard as outward deliverables. The package includes `scripts/writing_check.py`; it checks authored prose without audience-category or Markdown-quotation exemptions.

Exact source evidence and executable syntax stay as they are, while the newly written prose around them gets a full review. Run the checker and read the finished output before delivery.

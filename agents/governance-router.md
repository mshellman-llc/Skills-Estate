# Governance Router

1. Identify the client, engagement, lifecycle stage, requested artifact, audience, and decision supported.
2. Resolve and read the engagement AI Knowledge Hub when applicable.
3. Select one primary skill from the list below and only the necessary evidence and quality controls.
4. Explain ambiguous routing and request the missing distinction.
5. Do not reproduce the selected skill's methodology.
6. Confirm which Knowledge Hub files the workflow must read and update.

## Available skills

- `maintain-skills-estate`
- `load-project-context`
- `capture-knowledge`
- `check-knowledge-hub`
- `reconcile-knowledge`

Within `maintain-skills-estate`, select the embedded authoring mode to create or repair a skill, or the embedded release mode for another host or account. Read that mode's complete workflow. These modes remain supporting modules within the maintenance package.

Use `load-project-context` to start or resume work with the configured knowledge hub, `capture-knowledge` to save a decision or correction, `check-knowledge-hub` to diagnose its current state, and `reconcile-knowledge` to compare a folder with current authorities.

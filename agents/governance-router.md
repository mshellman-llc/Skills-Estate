# Governance Router

1. Identify the client, engagement, lifecycle stage, requested artifact, audience, and decision supported.
2. Resolve and read the engagement AI Knowledge Hub when applicable.
3. Select one primary skill from the list below and only the necessary evidence and quality controls.
4. Explain ambiguous routing and request the missing distinction.
5. Do not reproduce the selected skill's methodology.
6. Confirm which Knowledge Hub files the workflow must read and update.

## Available skills

- `skill-estate-sync`
- `beastmode-context`
- `beastmode-capture`
- `beastmode-health`
- `beastmode-reconcile`

Within Skill Estate Sync, select the embedded authoring mode to create or repair a skill, or the embedded release mode for another host or account. Read that mode's complete workflow. The former standalone names are retained source modules, not separate installed skills. Use the BeastMode skills for Megan's personal Hub: context to start or resume work, capture to save a decision or correction, health to check the Hub, and reconcile to compare a folder with current authorities.

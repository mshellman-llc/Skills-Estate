# Discovery brief

Read [shared workflow](references/estate/workflow.md). For a rendered or branded artifact, read [brand policy](references/estate/brand.md) before choosing visual values. These references are generated from the canonical policies when the estate builds.

Resolve the client, opportunity, session, and existing ledger. Read the authoritative internal record, RFP, current scope, and relevant transcripts. Keep a stable ID for each finding and question.

The ledger has supported findings with source locations and open questions with the scope or decision each answer unblocks. Rank questions by their effect on feasibility, cost, timeline, risk, and the next decision. Preserve contradictory evidence instead of selecting the most convenient answer.

When ingesting a call, match answers to existing question IDs. Close a question only when evidence answers it; narrow partial questions. Capture new findings and decisions with speaker, date, and transcript location. A suggestion is not a decision, and a request is not agreed scope.

Update the discovery record using the available revision-safe storage tool. Feed supported account facts back to the account record. Send proposed scope changes to scoping-agent with their evidence; do not silently change a quote. Re-rank remaining questions and show what changed, what remains open, and who can resolve it.

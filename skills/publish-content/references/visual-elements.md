# Visual elements

Prose is the default carrier. An exhibit earns a place only when it does a job prose does worse. Decorative images had no measurable effect in 12 studies, and interesting but irrelevant images reduced learning. [S65; S66; S71]

## Decision procedure (B4 runs it once per section claim and stops at the first failure)

1. Claim. Write the one sentence the element would prove; an element with no such sentence is cut. [S78; S81]
2. Function. Name one: represent (show the real thing), organize (structure or sequence), interpret (make a mechanism concrete), compare (exact values side by side), evidence (first-hand proof), personalize (the reader's own inputs). Decorating and breaking up text are not functions. [S65; S66; S71]
3. Prose test. One to three numbers, or a linear sequence of three or four steps, stays in a sentence or a numbered list. [S74; S80]
4. Task fit. Exact values go in a table. A shape, trend, gap, ranking or outlier goes in a chart whose form follows the relationship type. A system of parts and relations goes in a diagram. A procedure the reader has to learn gets a worked example. When the reader's inputs decide the answer, use a calculator. Recurring monitoring against targets needs a dashboard, which this engine almost never builds. [S73; S79; S69; S100]
5. Evidence. Every value, label, screen, photo and quote in the element has a register or asset ID. [S35; S108]
6. Reader. Novice: worked example, labels inside the figure, terms defined before it. Expert: the rule or reference, a diagram without explanatory text. [S67; S70]
7. Visibility. Anything a reader needs to decide or act stays in the page without a click, and in print. [S91; S92]
8. Record the exhibit in the ledger and place it directly after the sentence that makes its claim, with labels inside the graphic. Text placed beside its graphic beat separated layouts (g = 0.63). [S68]

## Per-genre visual contracts

| Genre | Earns a place | Must contain | Never |
| --- | --- | --- | --- |
| Blog | A chart of the owner's data behind the disputable claim; a real screenshot or photo; the worked example as text or a table | Takeaway title, a line naming the source, alt text stating the finding | Stock or decorative hero image; images of text or code; more than one callout |
| Conversational | Nothing by default; one screenshot or table when it is the answer | The answer in text before any visual | A visual standing in for the answer; carousels |
| Expository | Numbered steps (12 or fewer), code as text, cropped confirming screenshots, expected output, a worked example; concept or architecture diagram; comparison and parameter tables | Figure captions; a warning only for destructive or irreversible steps; diagram title with type and scope, key, labelled one-way arrows | Prerequisites or steps inside a note; stacked notices; a diagram for a three-step line |
| News | Photo of a witnessed scene; chart when the story turns on a quantity; map when place matters; timeline; document embed | Caption with who, what, where and when; source line; corrections cover graphics | Any AI-generated or AI-altered photo; non-central interactives |
| Review | Own photos or video of the unit and test setup; measurement chart or table with conditions; spec and comparison tables; verdict with best-for and not-for | Test conditions, units and dates | Manufacturer, stock or AI images offered as evidence |
| Case study, portfolio | Before-and-after; chosen option beside the rejected one; one rounded outcome with its baseline; context-level solution diagram; real or rebuilt screens | A caption naming the decision each artifact led to; rebuilt screens captioned as rebuilt; brand styling; only verbatim, approved pull quotes | Process-stage diagrams with no decision; client screens shown as real without permission; AI images of people or client sites; KPI tiles without a comparator |
| Case study, customer or consulting | Exhibit N with an action title; metric callouts with baseline, end value and timeframe; architecture diagram; timeline when sequence drove the result; logo with consent | Source line under each exhibit; in-text reference; permission on file | Analysis presented as data; logos or screens without consent |
| Proposal | Scope diagram; side-by-side options; price hierarchy; milestone timeline; a calculator only when the reader's numbers set the price | Recommendation, price, inclusions, exclusions, assumptions and terms visible without interaction and in print; approved figures only | Price or scope inside tabs, accordions or carousels; controls that imply acceptance, booking or saving unless connected and verified |

## Component selection matrix

| Element | Use when | Not when | Must contain |
| --- | --- | --- | --- |
| Table | Readers need exact values or compare options on the same rows | Two rows that read better as a sentence | Units, consistent row order, visible exclusions |
| Chart | The claim rests on a pattern and the data is verified | Exact values are the point; exploratory cuts with no takeaway | Takeaway title, units and period, hero colour plus grey, direct labels, 1 to 3 annotations, source line, alt text and data table |
| Diagram | Entities with branching relations, system parts | A linear three-step list | Title naming diagram type and scope, a key, typed boxes, labelled one-way arrows |
| Timeline | Sequence or timing drove the result | Dates that do not matter to the claim | Real dates, scale, the decision point marked |
| Worked example | A new reader must learn a procedure with interacting parts | Expert readers | A correct, complete example with real numbers |
| Screenshot | It saves words or confirms a step | It shows text that should be text | Crop, personal data covered, permission |
| Photo | Real subject, real event, first-hand evidence | Generic stock people or mood | Caption, credit, consent for people shown |
| Generated illustration | A metaphor carries the claim | Any real person, place or event; evidence | Live text in layout, IPTC tag, rights record |
| Metric callout | The number changes the reader's sense of scale or result | No comparator exists | Baseline or target, direction, timeframe, rounded |
| Dashboard | A named user returns to watch known measures against targets | One-off decisions, arguments, case studies | Comparators, trend, one screen |
| Note callout | One aside per piece | Anything required; stacked boxes | One idea; neutral surface, one accent; at most two per piece |
| Warning | Legal, financial, safety or irreversible consequences | Routine emphasis | The consequence in one plain sentence |
| Pull quote | A verbatim, approved quote from a named person | The owner's own sentence repeated; slogans | Name, title, approval on file |
| Before-and-after | The change is visible | The difference is invisible at page size | Both states labelled at the same scale; a slider also shows both states statically |
| Accordion | Independent sections where each reader needs one or two (FAQ, appendix) | Content all readers need; narrative; comparison | Descriptive headings, show-all control, content in the page and in print |
| Tabs | Two or three alternate views, one needed at a time | Comparison; steps; critical content off the first tab | Short labels; stacked fallback on mobile; all panels in the page |
| Calculator | The answer depends on the reader's own variables | Static facts; gated lead capture | Defaults, visible assumptions, estimate label, static default for print |
| Explorable | Readers should see how a claim moves with an assumption | A sandbox with no guided default | Guided default state, visible model, text equivalent of the result |
| Carousel | Almost never | Key messages | Five frames or fewer, labelled controls, pause |

## Image generation brief (for B5b step 4 and any design request)

Concept and the single focal point come first; the image must be readable at thumbnail size; palette and lighting follow the brand profile. Words, prices, dates and names are set as live text in the layout, never rendered in the image. A role line sets tone only. Before generating, answer "should this image exist?" through the decision procedure above. After generating, check at thumbnail and full size, record provenance, and route to the human sign-off.

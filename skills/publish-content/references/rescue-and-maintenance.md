# Rescue mode and maintenance

## Rescue mode: evolve existing AI-written text

Use when the input is an existing draft rather than a goal.

1. Run B6 layers 1 to 5 on the draft and count findings per layer. For an AI-written case study, first extract every number, name, date and quote and trace each; cut anything untraceable before any edit. If the decision and its alternatives cannot be recovered from owner records, choose Rebuild through B3. [S40; S58] Inventory every visual: cut decorative ones, rebuild misleading charts from data, trace every number in a graphic, and label or replace recreations. [S65; S82]
2. Recover the brief: what reader, job and thesis does the draft imply? If none can be stated, the draft has no brief.
3. Decide, and say which:
   - Edit: substance layer has few findings and the thesis holds. Run B6 then B7.
   - Rebuild: the thesis holds but the evidence is thin. Return to B2 and B3 for assets, then B4 onward, keeping only sentences that survive B7.
   - Retire: no reader job, no information-gain asset available, or the topic duplicates stronger pages. Recommend removing or merging, with the reason. [S3 updating beats deleting when the page has traffic or links]
4. Report the decision first, then the findings by layer, then the plan.

## Maintain the engine

1. Keep one copy of each prompt block under version control, with the version number and changelog at the top. Variants for a client or channel live in the owner profile, never as edited copies of the agent procedures. This prevents near-duplicate prompts drifting apart. [S19]
2. Change one block at a time. Before adopting a change, run the old and new block on the same three past pieces and compare the defect log counts and panel scores, using the judge controls in orchestrator rule 5.
3. Review the defect log monthly. A pattern that leads for three months points to a gap in a prompt block or the brief; fix the block, then log the change in the changelog.
4. Give each agent its procedure, inputs, checks and output format. A role line sets register only; it does not raise accuracy. [S10]
5. Test quarterly that the CMS keeps IPTC and C2PA metadata. [S119]

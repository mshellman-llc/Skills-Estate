# Playbook fit router

Read [shared workflow](references/estate/workflow.md). For rendered artifacts, read [brand policy](references/estate/brand.md).

Read the available catalog and each relevant qualifier, then the named discovery sources. State catalog coverage if any entry is unavailable. Preserve client-stated, observed, and inferred signals separately.

Evaluate each candidate against its actual fit criteria. Every positive signal and disqualifier needs supporting evidence. A negated mention is not positive fit, and an inference cannot establish a confirmed disqualification. Leave unanswered gates open.

Rank the plausible options using the catalog's defined method. If no scoring method exists, provide a qualitative comparison with explicit reasoning instead of invented numeric precision. Explain the strongest match and credible alternatives.

Return the fit recommendation, supporting citations, unanswered questions, and any tier hypothesis. Do not lock a tier, price an offering, create a quote, or claim complete routing when catalog coverage is incomplete.

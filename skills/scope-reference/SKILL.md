# Scope reference

Read [shared workflow](references/estate/workflow.md). For a rendered or branded artifact, read [brand policy](references/estate/brand.md) before choosing visual values. These references are generated from the canonical policies when the estate builds.

Resolve every option and its current quote or approved source. Use stable item IDs to compare the same work across options. Keep included, available, optional, and excluded states distinct; an absent row is not automatically excluded.

Reconcile each item name, effort value, and inclusion state to its source. Use each option's authoritative total and timeline snapshot. Do not calculate a headline fixed fee by adding line-item hours unless the pricing source defines that formula.

Show a concise option overview and a full matrix that can be read at once. Explain differences through actual scope and delivery trade-offs. Do not hide excluded rows or turn optional work into a commitment. Mark unknown values accurately in the working record and resolve any missing value that would make the comparison misleading.

Render in the requested format with the shared brand policy. Test printing, repeated headers, narrow columns, and legibility. Compare the finished matrix and totals with the source records and identify the quote revisions used. Preparing this reference does not change a quote.

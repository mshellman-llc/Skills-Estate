# Process

Read [shared workflow](references/estate/workflow.md). For a rendered or branded artifact, read [brand policy](references/estate/brand.md) before choosing visual values. These references are generated from the canonical policies when the estate builds.

Choose document or optimize mode. Identify trigger, end state, scope, process owner, participants, systems, and current evidence. Use observed behavior for the current state; keep the proposed future state separate.

For an SOP, describe purpose, inputs, outputs, sequence, responsibilities, decision points, exceptions, escalation, and measures. Use a RACI only where it clarifies responsibility and ensure each decision has a clear accountable owner. Show handoffs and required records.

For optimization, map steps and waiting time, find the constraint, and distinguish rework, batching, unnecessary approval, and missing information. Propose a change tied to the constraint. Explain affected roles, controls, and implementation dependencies.

Quantify benefits only from supplied measurements or clearly labeled assumptions with calculations. Define how a pilot would measure the result. Deliver the requested process record or improvement plan without claiming the proposed process has been adopted.

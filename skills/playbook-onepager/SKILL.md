# Playbook onepager

Read [shared workflow](references/estate/workflow.md). For rendered artifacts, read [brand policy](references/estate/brand.md).

Read the current offering record and choose internal, external, or both outputs. The internal brief can include qualification, disqualifiers, delivery mechanics, economics where authorized, and the sales handoff. The external page explains the buyer's problem, outcome, included scope, boundaries, and next action.

Use the same source definition for both pages while respecting audience differences. Do not expose internal margins, delivery risks framed for the team, or client-specific evidence in an external handout. Preserve stated prices and terms only when approved for that audience.

Apply the shared brand policy through the available document or PDF tool. Keep the page legible at its real physical size. A one-page request does not justify unreadable type or dropping material scope limits.

Render and inspect each page, compare facts across versions, and check links and metadata. For a catalog batch, reconcile the output count and every offering ID. Generating handouts does not publish the catalog.

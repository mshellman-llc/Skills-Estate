# Journey mapping

Map one actor's experience across touchpoints, goals, thoughts, feelings and friction. Connect the journey to its service blueprint and a prioritized improvement to validate.

Start with [SKILL.md](SKILL.md), then read [the complete method](references/method.md) and [the template](references/journey-map-template.md) for the linked views. The [HTML starter](assets/journey-map.html) supports qualitative feelings without invented scores. Shared writing and branding rules are added by the estate build.

Use the template’s source ledger for a standalone research map. For shared project records, resolve storage through `manage-consulting-knowledge`; governed client maps also use `evidence-core`. Run `review-deliverable` for the applicable delivery checks. Rendering requires inspection of the actual output.

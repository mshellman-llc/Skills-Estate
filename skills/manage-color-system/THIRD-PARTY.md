# Third-party code

`scripts/vendor/deps.mjs` bundles two libraries. Their license notices are kept inline in the bundle.

| Library | License | Used for |
| --- | --- | --- |
| Material Color Utilities (`@material/material-color-utilities`), Google | Apache License 2.0 | HCT color space, tonal palettes, Material 3 schemes, harmonization |
| culori | MIT | Color parsing, OKLab and OKLCH conversion, color-vision deficiency simulation |

`scripts/lib/apca.mjs` is written for this skill from the published APCA 0.0.98G-4g constants.
